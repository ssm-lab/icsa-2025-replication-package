## RA components tables

RA components tables in the publication, listing each component and the frameworks that implement it.
Tables are in two formats, in the respective `latex/` and `pdf/` subfolders.
The corresponding BibTeX entries of frameworks are provided in `latex/sources.bib`.

These tables are generated from `02-data/03-final-RA.xlsx` (sheet: `final-RA-to-framework-summary`)
by using `03-analysis/table_generator.py` script.
